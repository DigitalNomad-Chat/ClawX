LicenseModule（复用改造）
新增:
• Feature Token payload 增加 usage 字段
• POST /api/v1/license/issue 支持 ClawX client_type
• 设备绑定支持多产品（guada_ai + ClawX）
不变: RSA 签发/验签逻辑保持不变
⚠️ 关键设计决策
  • 计数周期：自然月（每月1日00:00重置），与后端数据库的 MonthlyQuota 表同步
  • 计数维度：协作大厅每次"新建任务"计1次；应用广场每次"雇佣Agent并发送首条消息"计1次
  • 离线策略：离线时依赖本地计数 + Feature Token，恢复联网后向服务端同步并校准计数
  • 安全：本地计数文件使用 electron-store 加密存储，防止篡改；校验失败则强制在线验证
