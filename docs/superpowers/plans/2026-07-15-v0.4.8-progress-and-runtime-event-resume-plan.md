## 4. #1094 确认决策（只读规划结论）

| 决策 | 内容 |
|------|------|
| 接入方式 | **Adapter**：保留 ClawDock 自定义 host API/行为，不整包覆盖 |
| 事件策略 | Main **dual-emit**：`chat:runtime-event`（normalize 后）+ 现有 `gateway:notification`（agent） |
| 过渡期 | 保留旧 **agent notification → handleChatEvent** 与 **history poll**，直到 runtime 流证据充分再收敛 |
| 非目标 | **`#1094` ≠ v0.4.9 IPC 重构**（~31 文件事件管道 vs ~285 文件 host-contract/api 大搬迁） |
| 对照 commit | 上游 `8ea306d9`；当前缺 `shared/chat-runtime-events.ts`、`electron/gateway/chat-runtime-events.ts`、`runtime-graph.ts`、preload/host-events 的 `chat:runtime-event` 全链路；`ws-client` 仍为 `caps: []` |

### 当前 vs 上游事件流（摘要）

- **上游：** caps `tool-events` → normalize agent → `chat:runtime-event` → Main/IPC/preload/host-events → `handleRuntimeEvent` + `runtimeRuns` → Execution Graph 流驱动；agent raw 不再作 chat 主源。
- **当前：** caps `[]`；agent 仅 notification；gateway store 解析 phase/state → `handleChatEvent` + history poll；`phase === 'end'` 不当 run 终结（ClawDock 修复，必须保留语义直到 adapter 等价覆盖）。

### ClawDock 边界分类（恢复时遵守）

- **保留：** host-api-proxy、sessions 增强、send-with-media 长超时、图片 settle / stale send / New Chat 运行态、`phase=end` 语义、心跳恢复、member/office-tools。
- **Adapter 引入：** shared 契约、Main normalize、dual-emit、caps、preload/host-events 映射、store `handleRuntimeEvent` 与旧路径并存、UI 活跃图切 runtime（历史 fallback）。
- **人工决策（M4 前再拍板）：** 双路径下线时机、是否强行改 POST `/api/chat/send`（建议不必）、poll 移除门槛、OpenClaw 5.20 对 `tool-events` 握手兼容。
