### 6.2 Item tool compatibility（`1b9809e3` → `527683fa`）

**背景：** OpenClaw 上 `stream=tool` 往往 **recipient-gated**（仅发起 client 可见）；`stream=item` 对 tool 步骤 **broadcast**。未映射时 dual-emit 只能从 notification 侧看到工具，runtime-event 缺 tool.*。

| 变更 | 说明 |
|------|------|
| Normalize | `stream=item` 且 **`kind === 'tool'`** → `tool.started` / `tool.updated` / `tool.completed`（按 item phase/status） |
| 严格 kind | 禁止缺省 kind 误映射；仅显式 `kind=tool` |
| Graph merge | 按 `toolCallId` 双流合并；**保留更丰富的 args/result**（防 reverse-order 覆盖变空） |
| Spec | `harness/specs/tasks/chat-runtime-item-tool-compat.md` |

### 6.3 M4.2 — 受限 history poll 收敛（`cb58b38b` → `e77d9129` → `ced5c587`）

#### 6.3.1 精确定义：`decideHistoryPollTick` 动作序

实现：`src/stores/chat/history-poll.ts` + 接线 `runtime-send-actions.ts` / 单体 `chat.ts` poll 路径。

每次 timer tick **严格按序**决定：

| 次序 | Action | 条件 | 效果 |
|------|--------|------|------|
| 1 | `stop` | `!sending` | 停止 poll 循环 |
| 2 | `defer-streaming` | 存在 streaming message | 不 load；稍后重调度 |
| 3 | `defer-silence` | 距 `lastChatEventAt` 仍在 silence 窗口内 | 不 load |
| 4 | `skip-runtime` | `shouldSkipHistoryPollForRuntimeEvidence(gate)` 为真 | **不**调用 `loadHistory`；**仍** reschedule（约 2s） |
| 5 | `load` | 以上皆否 | **`loadHistory(true)`** — **默认安全回退** |

#### 6.3.2 `skip-runtime` 门禁（全部满足才可 skip）

`POLL_CONVERGENCE_ENABLED === true`（当前 **true**，`runtime-evidence.ts`）**且** `evaluateRuntimePollGate` 全部通过：

| 门禁 | 含义 |
|------|------|
| `requireLiveProviderToolChainEvidence` | **本 runId** 已闩上 live tool-chain 证据（`Map<runId, scope>`；**禁止**进程级 sticky） |
| `requireActiveRunId` | 存在 `activeRunId` 且与 run 匹配 |
| `requireRunRunning` | run status 为 running（completed/error/aborted **永不** skip） |
| `requireSessionKeyMatch` | run 上有 sessionKey 时必须与当前 session 一致 |
| `requireToolActivity` | 该 run 有 tool/process 类 runtime 活动 |
| freshness ≤ **5s** | `RUNTIME_FRESHNESS_WINDOW_MS = 5000`；陈旧则 load |
| `rejectPendingFinal` | `pendingFinal` 时 **永不** skip（history/image settle 不确定性） |

任一不确定 → **`load`**。**legacy poll 路径永不删除**。

#### 6.3.3 Live evidence 生命周期（`ced5c587`）

- 证据 scoped：**per `runId`**（可选 sessionKey 校验）
- tool-like runtime 事件闩证据；**`run.ended` 清除该 run 证据**
- 旧 run 的证据 **不能** 授权新 `activeRunId` 的 skip
- 回退开关：出问题立即 `POLL_CONVERGENCE_ENABLED = false` 恢复全量 poll（见 `M4_POLL_ROLLBACK_BOUNDARIES`）

#### 6.3.4 回滚边界（文档常量，触发则关 flag）

- 多轮 tool 中 Thinking/stop 控制中途消失
- `phase=end` 被当成 run 终结
- 图片 settle 回归
- stale send / New Chat run-cache 回归
- runtime 覆盖不足导致 history 落后
- comms message_loss / 顺序违规

#### 6.3.5 单元证明

- `tests/unit/chat-history-poll.test.ts`：stop / defer / skip / load 序；recovery（证据过期或 run 切换后回到 load）
- `tests/unit/chat-runtime-evidence.test.ts`：per-run 证据、session 不匹配、pendingFinal、flag off
