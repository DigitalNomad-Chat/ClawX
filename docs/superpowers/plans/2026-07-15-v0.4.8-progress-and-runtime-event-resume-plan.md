### 2.2 契约摘要

- **Base：** `runId`（必填）、`sessionKey?`、`seq?`、`ts?`
- **Types：** `run.started` / `run.ended` / `assistant.delta` / `thinking.delta` / `tool.started|updated|completed` / `command.output` / `patch.completed` / `approval.updated`
- **Normalize 安全：** 非对象、缺 `runId`、未知 stream、缺 toolCallId/name → `null`（不 emit runtime-event）
