#### 2.1.2 `settings:get` / `settings:getAll` / `settings:set` / `settings:reset`

- **Main handler：** `electron/main/ipc-handlers.ts:2216-2230`
  ```ts
  ipcMain.handle('settings:get', async (_, key: keyof AppSettings) => { ... });
  ipcMain.handle('settings:getAll', async () => { ... });
  ipcMain.handle('settings:set', async (_, key, value) => { ... });
  ipcMain.handle('settings:reset', async () => { ... });
  ```
- **preload 白名单：** `electron/preload/index.ts:47-51`
- **host-api-client fallback：** 仅 `settings:setMany` 有 fallback；其余无
- **hostApi action：** `createSettingsApi` 在 Main 已注册 `get/getAll/set/setMany/reset`，但 `src/lib/host-api.ts` 仅暴露 `settings.setMany`
- **src 真实调用（注意统一路由）：**
  - `settings:getAll`：`src/components/models/QuickModelSwitchDialog.tsx:64-67` — `invokeIpc('settings:getAll', [])`。**该通道在 `src/lib/api-client.ts` 的 `UNIFIED_CHANNELS` 中，实际走 `app:request` 统一路由，不会命中 legacy `settings:getAll` handler。**
  - `settings:get`：`src/lib/api-client.ts:646` — `invokeViaIpc('settings:get', [{ key: 'gatewayToken' }])`。**同样走 `app:request` 统一路由。**

- **tests/harness 真实调用：**
  - `settings:getAll`：`tests/e2e/p4b-b2-settings-setmany.spec.ts:90`、`tests/e2e/settings-proxy.spec.ts:14`、`tests/unit/api-client.test.ts:35,87,89`
  - `settings:set`：`tests/unit/api-client.test.ts:96`
  - `settings:reset`：无
- **事件/二开依赖：** 无
- **判定：可删。** 由于 `settings:get/getAll` 在 renderer 中经 `app:request` 统一路由，删除 legacy handler 与 preload 白名单后，renderer 功能不受影响；但为避免残留通道字符串并统一迁移到 `hostApi.settings.*`，建议后续可选任务：在 `src/lib/host-api.ts` / `host-api-client.ts` 暴露 `settings.get/getAll/set/reset` 并将 `QuickModelSwitchDialog.tsx`、`api-client.ts:646` 迁移。当前 P5-D 范围内可直接删除 legacy handler。

## 4. 与 f66d8dc1 审计的差异说明

- f66d8dc1 将 `settings:*（除 setMany）` 判定为「无 renderer 直接调用，仅剩 fallback」。
- 本次重扫发现 `settings:getAll`（`QuickModelSwitchDialog.tsx:64`）与 `settings:get`（`api-client.ts:646`）存在 renderer 直接 `invokeIpc`/`invokeViaIpc` 引用，但均命中 `src/lib/api-client.ts` 的 `UNIFIED_CHANNELS`，实际通过 `app:request` 统一路由，不会落到 legacy handler。因此不影响「legacy handler 可删」的结论，但需在报告中明确：删除 legacy handler 后，renderer 仍保留通道字符串引用，未来统一迁移到 `hostApi.settings.*` 可进一步清理。

## 5. 通用回滚门槛

任一批次若导致以下任一失败，立即 `git revert` 该批次 commit 并回传 lead：

1. `pnpm run typecheck` 失败；
2. 相关 unit/E2E 测试失败；
3. `pnpm run harness:ci` 失败；
4. `git diff --check` 发现空白/换行问题。
