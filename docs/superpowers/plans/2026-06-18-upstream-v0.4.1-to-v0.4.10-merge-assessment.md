## 四、推荐合并路线

### 路线：先低风险 bugfix，再高风险重构

```
Step 1: v0.4.1 → v0.4.2（model picker）
Step 2: v0.4.4 → v0.4.5（chat/OAuth bugfix）
Step 3: v0.4.5 → v0.4.6（installer 优化，可选）
Step 4: v0.4.6 → v0.4.7（OpenClaw 5.19 + image gen）
Step 5: v0.4.7 → v0.4.8（OpenClaw 5.20 + Gateway 心跳）
Step 6: v0.4.8 → v0.4.9（IPC Runtime 重构，独立里程碑）
Step 7: v0.4.9 → v0.4.10（OpenClaw 2026.6.5 + provider 修复）
```

每个 Step 单独创建一个分支：
```
feat/membership-system-merge-v0.4.2
feat/membership-system-merge-v0.4.5
...
```

每个 Step 完成后：
1. 解决冲突
2. 运行 typecheck
3. 运行相关单元测试
4. 确认无 regressions
5. 合并回 `feat/membership-system`
