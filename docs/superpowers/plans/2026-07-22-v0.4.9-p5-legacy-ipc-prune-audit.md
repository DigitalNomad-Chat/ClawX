## 2. 优先批次详细审计

### 2.1 批次 A — `skill:*` config

**对应 hostApi action：**
- `host:invoke` 已注册：`skills.getConfig` / `skills.getAllConfigs` / `skills.updateConfig`（见 `electron/services/skills-api.ts`）
- 但 `src/lib/host-api.ts` 当前**未暴露** `hostApi.skills`，因为 renderer 无调用。

**rg 证据：**
```bash
rg "skill:(updateConfig|getConfig|getAllConfigs)" src electron tests harness --type ts --type tsx
# 命中：
# - electron/preload/index.ts（白名单）
# - electron/main/ipc-handlers.ts（handler）
# - tests/e2e/p3c-skills-config.spec.ts（直接调用 legacy 通道）
# src/ 无命中
```

**真实业务调用：**
- Renderer：无
- Tests：`tests/e2e/p3c-skills-config.spec.ts` 直接 `window.electron.ipcRenderer.invoke('skill:getAllConfigs')` 等
- Harness：仅有历史提及（`v049-ipc-p4b-b6/b7` 注释），不计为调用

**二开依赖：** 未在 `electron/extensions/` / `electron/modules/` 发现调用。

**可删除条件：**
1. 删除 `electron/main/ipc-handlers.ts` 中 `registerSkillConfigHandlers()` 的三个 `ipcMain.handle('skill:*')`。
2. 从 `electron/preload/index.ts` invoke 白名单移除三个 `skill:*`。
3. 更新/删除 `tests/e2e/p3c-skills-config.spec.ts`：改为通过 `host:invoke` 测试 `skills.getConfig/getAllConfigs/updateConfig`，或删除该测试（因 production 已无此入口）。

**验证 / 回滚：**
- `pnpm run typecheck`
- `pnpm exec playwright test tests/e2e/p3c-skills-config.spec.ts`（若保留并迁移）
- `pnpm run harness:ci`
- 任一失败：`git revert` 本批次 commit。

### 2.3 批次 C — `dialog:save/message` + `shell:showItemInFolder`

**对应 hostApi action：**
- `hostApi.dialog.save` / `hostApi.dialog.message`
- `hostApi.shell.showItemInFolder`
- 均已存在于 `src/lib/host-api.ts` 与 `src/lib/host-api-client.ts` fallback。

**rg 证据：**
```bash
rg "invokeIpc\(['\"](dialog:save|dialog:message|shell:showItemInFolder)" src tests harness --type ts --type tsx
# src/ 命中：
# - src/lib/host-api-client.ts（fallback 调用）
# 无其他直接业务调用
```

**真实业务调用：**
- Renderer：无直接调用
- Tests：无

**可删除条件：**
1. 删除 `electron/main/ipc-handlers.ts` 中 `registerDialogHandlers()` 的 `dialog:save/message` 与 `registerShellHandlers()` 的 `shell:showItemInFolder`。
2. 从 `electron/preload/index.ts` invoke 白名单移除对应条目。
3. 从 `src/lib/host-api-client.ts` 移除 `dialog.save/message` 与 `shell.showItemInFolder` 的 fallback 分支。
4. 确认 `hostApi.shell.showItemInFolder` 的 unit/E2E 覆盖已存在（B6 已补）。

**验证 / 回滚：**
- `pnpm run typecheck`
- `pnpm exec vitest run tests/unit/host-api-facade.test.ts`
- `pnpm run harness:ci`
- 任一失败：`git revert`。
