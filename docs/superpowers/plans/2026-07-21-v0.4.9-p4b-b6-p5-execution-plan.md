- [ ] lead **书面授权 P5**（与 P4b 开闸分离）

### 8.2 零调用证据定义

对每一条候选删除的 legacy channel，必须提供：

1. 零调用证据扫描：执行 `rg "channel-name" src electron tests harness`；范围必须包含 `harness/specs`。`docs/`、`*.md`、代码注释（`//` / `/*`）及测试夹具说明中的历史提及**不计**为有效调用，须用 `-g '!docs/**' -g '!*.md'` 或等价方式排除后出具表格。renderer / preload **无业务调用**。
2. 对应 `hostApi` action 已有 unit +（若 UI）E2E 覆盖。
3. harness rule/task 已更新并 `harness validate` PASS。
4. lead 确认 ClawDock 二开（member/office-tools/desensitize/hermes）无依赖。
5. 该通道 **不在** 默认保留清单内。

**默认保留项（本阶段不得删除，除非另批书面批准）：**

- `hostapi:fetch` / `hostapi:token`
- `gateway:rpc` / `gateway:httpProxy`
- `chat:runtime-event` 与 dual-emit 相关
- `chat:sendWithMedia`
- auth/member、office-tools、desensitize 专用通道

### 8.3 执行序

```text
0. lead 授权 + 冻结「候选删除清单」
1. harness：收紧 prune 政策（先测试）
2. 按通道：rg 证据表 → 删 handler → unit/E2E/harness
3. 可选：HTTP route 收敛（仅当 hostapi:fetch 调用图为空或只剩二开）
4. docs：标记 P5 完成与 residual channels
5. 双轨保留窗口建议 ≥ 一个发布周期
```
