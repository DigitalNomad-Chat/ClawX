# v0.4.9 Electron IPC Runtime 分阶段迁移计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **当前状态：** **仅计划文档已落库**。**禁止自动启动 P0 实现**、禁止触碰 v0.4.10 / skills marketplace 解耦，须 lead **新授权**后从 **P0** 串行执行。

> **上游对照：** `581981f2` — `refactor: Unify Electron IPC Runtime, Shared Contracts, and App UX/DX Fixes (#1102)`  
> **本地基线：** 分支 `feat/membership-system-merge-v0.4.8`，计划撰写时 HEAD = **`0ce0505e`**（docs archive）；**#1094 功能 HEAD = `ced5c587`（M4.2）**。

**Goal:** 以 **adapter / 选择性移植**（非整 commit cherry-pick）将上游 `#1102`（`581981f2`）的 Electron IPC Runtime 与 Shared Contracts 迁入 ClawDock，统一 renderer→Main 调用为类型化 `hostInvoke(module, action, payload?)`，同时 **完整保留** #1094 M4 runtime dual-emit / 受限 poll、现有 Host API 代理语义、会话/媒体、图片 settle / stale send / New Chat，并在 **P1** 消除 AgentChat 直接 `ipcRenderer.invoke` 预存债。

**Architecture:** 当前 ClawDock 为 **双栈**：Main 巨型 `ipc-handlers.ts`（~100+ `ipcMain.handle`）+ HTTP Host API（`electron/api/server.ts` + routes）+ renderer `hostapi:fetch` 代理（`host-api-proxy.ts`，端口 `CLAWDOCK_HOST_API`/13210）+ `api-client` IPC 网关。上游 `581981f2` 收敛为 **HostServiceRegistry + host-contract/host-invoke + `electron/services/*-api.ts` + shared contracts + renderer `hostApi` facade**，并删除旧 HTTP route 层与 `api-client` 单体。本计划采用 **并行双轨 → 门禁裁剪**：先加 registry/contract 与服务模块，再迁 renderer facade，最后在证据充分后 prune 已被覆盖的 legacy channel；**不**一次删除 ClawDock 的 `hostapi:fetch` / HTTP Host API，直到 P5 验收证明 `hostInvoke` 覆盖等价路径。

**Tech Stack:** TypeScript / Electron / React 19 / Vite / pnpm / Vitest / Playwright / OpenClaw bundled runtime（当前 `2026.5.20`）/ harness（gateway-backend-communication）/ 现有 host-api fallback 策略

## Global Constraints

- **选择性移植**：禁止 `git merge` / 整 tag 合入 `v0.4.9`；禁止整包 cherry-pick `581981f2`（~285 文件含 UX/i18n/sidebar 等非 IPC 核心）。按 P0–P5 **最小文件集合** patch。
- **串行依赖（强制）**：`P0 → P1 → P2 → P3 → P4 → P5`。禁止并行开多阶段；**本任务仅写计划，不启动 P0**。
- **保留 #1094 M4（硬约束）**：
  - Main dual-emit：`chat:runtime-event` + `gateway:notification`
  - `phase=end` **非** `run.ended`

  - 相关文件（`electron/gateway/chat-runtime-events.ts`、`event-dispatch.ts`、`src/stores/chat/runtime-*`、`history-poll.ts` 等）仅允许为 path alias / 导入适配做 **机械改动**，禁止改语义。
- **保留 Host API 与 ClawDock 代理语义**：

- **保留会话 / 媒体 / 聊天关键行为**：
  - sessions 增强路由与 history 合并语义
  - media / `chat:sendWithMedia` **180s** 长超时
  - 图片 settle（delivered history media）、stale send generation、New Chat 不误清他会话 run cache
- **保留 ClawDock 二开模块（不得被上游删除清单冲掉）**：
  - `package.json` 的 `name` / `version` / `upstream` / `mergeDate` / 自定义 `scripts`

  - office-tools、desensitize、hermes-proxy 等 HTTP/服务路径

- **P1 必须处理 AgentChat direct IPC 债**（见 §P1；对应 #1094 归档残留 R1）。
- **明确排除（本计划全阶段）**：

  - **skills marketplace 解耦** / ClawHub 大改（仅当服务搬迁机械需要时 touch 边界文件，不做产品行为变更）
  - 上游 `581981f2` 中纯 UX/DX 旁支（Sidebar 大改、confirm-dialog 视觉、menu i18n 大搬迁等）— 另任务；本计划可引用但 **不实现**

- **Comms / harness**：触及通信路径须有 `harness/specs/tasks/*` 并引用 `gateway-backend-communication`；验证优先 unit + typecheck + 相关 harness validate；comms 路径改动跑 `comms:replay` / `comms:compare`。
