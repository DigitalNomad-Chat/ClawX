# 会员系统云迁移重构总结

> 执行日期：2026-05-31
> 执行分支：feat/membership-system
> 目标架构：NestJS + Prisma + PostgreSQL（云端优先）

---

## 一、任务目标

将 ClawX 项目的会员系统从**本地优先架构**彻底重构为**云端优先架构**：

- **原架构**：Electron 主进程本地 SQLite（better-sqlite3）+ bcryptjs 本地密码哈希 + jsonwebtoken 本地 JWT 自签发 + Cloudflare Workers（仅 License 验证）
- **目标架构**：Electron 纯 HTTP 代理 → 自建 NestJS + Prisma + PostgreSQL 云后端（纯云端 JWT，无离线支持）

核心诉求：
1. 所有认证逻辑（注册、登录、登出、用户资料、用量统计、功能检查、License 激活）全部通过云端 API 完成
2. Electron 客户端仅作为轻量级 HTTP 代理，本地不再存储用户敏感数据
3. 后端部署在自有的云服务器上（腾讯云香港）

## 五、风险与后续事项
